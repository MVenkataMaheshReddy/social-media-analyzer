# Social Media Content Analyzer

A full-stack prototype that parses PDFs and extracts text from images using OCR to analyze post structure and provide engagement feedback.

## Setup & Running Locally

1. Install Tesseract OCR on your machine:
   - **Mac:** `brew install tesseract`
   - **Ubuntu:** `sudo apt install tesseract-ocr`
   - **Windows:** Download binary from GitHub (`UB-Mannheim/tesseract/wiki`)

2. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
